# Needle for YouTube: the guide site

This repo is the site at **https://gottostartsomewhere.github.io/needle/**, the how-to guides for
[Needle for YouTube](https://chromewebstore.google.com/detail/needle-for-youtube-channe/magofcbhfhpfabphcldhodhgehhclokc),
a Chrome extension that searches the parts of YouTube that have no search box.
